Free IP Geolocation API

🔑 API will probably be available one day...

Our API is available with a subscription plan. To access the API, you'll need to register and obtain an API key.

🌐 How to Use

Send a GET request to the following URL with your API token:

https://ip.mysearch.one/api.php?ip=8.8.8.8&token=xyz123abc456def789ghi

Replace 8.8.8.8 with the IP address you want to check and xyz123abc456def789ghi with your API token.

You can also get browser information by sending a user agent:

https://ip.mysearch.one/api.php?browser=Mozilla/5.0...&token=xyz123abc456def789ghi

Both parameters can be combined in a single request:

https://ip.mysearch.one/api.php?ip=8.8.8.8&browser=Mozilla/5.0...&token=xyz123abc456def789ghi

To get information about your current IP address or browser, you can use the keywords my, this, or current:

https://ip.mysearch.one/api.php?ip=my&browser=current&token=xyz123abc456def789ghi
